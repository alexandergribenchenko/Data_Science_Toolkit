# 00. Ambientes vituales con venv (alternativa previa a uv)
- `python -m venv venv`: crear un entorno virtual.
- `.\venv\Scripts\Activate.ps1`: activar el entorno virtual.
- `pip install pandas numpy`: installar las dependencias necesarias con pip.
- `pip list`: verificar que las dependencias estan instaladas.

# 01. Instalar `uv`

# 02. Comabdos `uv`
- `cd [proyecto]`: ir a la carpeta del proyecto.
- `uv init`: inicializa un proyecto Python y crea archivos base como `pyproject.toml`, `.python-version` y `README.md`.
- `uv venv`: crea un entorno virtual (`.venv`) *(opcional si usas `uv sync`)*.
- `.venv\Scripts\activate`: activa el entorno virtual (Windows).
- `uv add [paquete]`: instala una dependencia y la registra en `pyproject.toml`.
- `uv add -r requirements.txt`: instala dependencias desde `requirements.txt` y las agrega al proyecto.
- `uv remove [paquete]`: elimina una dependencia del proyecto.
- `uv sync`: crea el entorno virtual (si no existe) e instala todo lo definido en `pyproject.toml` y `uv.lock`.
- `uv run [script.py]`: ejecuta un script dentro del entorno del proyecto (sin necesidad de activarlo manualmente).
- `uv run --env-file=.env [script.py]`: ejecuta un script cargando variables de entorno desde `.env`.
- `python test.py`: ejecuta el script usando el entorno activo (equivalente a `uv run` si ya estás dentro del venv).
- `uv pip list`: muestra los paquetes instalados en el entorno virtual.
- `uv tree`: muestra el árbol de dependencias del proyecto.
- `uv export --format requirements.txt --no-emit-project --no-hashes --output-file requirements.txt`: genera un `requirements.txt` desde el proyecto.
